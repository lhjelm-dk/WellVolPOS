# Screenshots

Images used by the project `README.md` and by any write-up about the tool.

**Drop PNGs straight into this folder.** Nothing reads it automatically — the
README links whatever is here by name, so a file that is not linked is simply
unused rather than broken.

## Naming

Use the figure's number as it appears in the app, then a short slug:

```
3.2_chance-decomposition.png
4.1_outcome-tree.png
```

A screenshot of a whole tab, or of something that is not one figure, takes a
plain descriptive name instead — `tab3-where-to-drill.png`.

## Which prospect

**Prospect C**, the default. It is the only published dataset with a chance table
carrying real numbers, so it is the one whose figures show the argument the README
makes — a prospect POS of 45 % against a well POS that runs from 45 % down to 4 %
across the same structure. Prospect A works but has POS 76 % from the trials
themselves, which makes the gap look smaller than it is on ordinary data.

Say which prospect and which well any image was taken at, in the README caption.
An image of a chance without its location is the thing this tool exists to argue
against.
